# OpsMind AI: Intelligent Management Orchestrator 🧠🤖

**OpsMind AI** is an advanced autonomous agent system designed to bridge the gap between Natural Language and complex system operations. Moving beyond simple chatbots, OpsMind acts as a digital "Operator" capable of managing users, processing documentation, and overseeing organizational workflows through a unified chat interface.

## 🚀 Project Vision
The goal of OpsMind AI is to create a "Manager Agent" that doesn't just answer questions but **executes tasks**. It leverages RAG (Retrieval-Augmented Generation) for policy intelligence and Function Calling to interact with live databases and microservices.

## 🛠️ Tech Stack
* **Core AI:** Gemini AI (Function Calling, Agents, Vision)
* **Backend:** FastAPI (Microservices Orchestration) & Python (Advanced OOP)
* **Frontend:** Streamlit (Admin Dashboards)
* **Databases:** MongoDB (NoSQL User Data) & Supabase (Vector Store for RAG)
* **Automation:** n8n (Workflows), Playwright (Web Tasks), & Celery/Redis (Async Tasks)
* **DevOps:** Docker, Google Cloud Run, & Firebase Auth

## 📋 Key Features
- **Natural Language Querying:** "Find all interns who joined last month" translates into structured database queries.
- **Document Intelligence:** Automated OCR and parsing of invoices/resumes using Gemini Vision.
- **Agentic Workflows:** Background report generation via Celery and automated web actions via Playwright.
- **Policy RAG:** Semantic search through company handbooks stored in Supabase vector clusters.

## 📂 Project Structure
* `PHASE 0/`: Foundations, Data Modeling, and Log Analysis.
* `PHASE 1/`: Admin Dashboards (Streamlit) and REST APIs (FastAPI).
* `PHASE 2/`: System Memory (Mongo/Supabase) and Async Workers (Celery).
* `PHASE 3/`: The AI Core & Manager Agent implementation.
* `PHASE 4/`: Security, n8n Workflows, and Cloud Deployment.

4. Set up environment variables in a `.env` file (Refer to `.env.example`).
